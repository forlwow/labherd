# web 设计

技术选型见 [ADR 0005](../adr/0005-web-stack-and-embedding.md)，运行方式见 [components/web.md](../components/web.md)。

## 职责

给实验室同学看服务器现状，首先回答"现在哪张卡是空的、哪块盘还有空间"。M1 只读，不做操作。

## 模块划分

| 模块 | 位置                  | 内容                                          |
| ---- | --------------------- | --------------------------------------------- |
| 接口 | `web/src/api/`        | 与 `/api/v1/` 对应的类型、请求函数、轮询 Hook |
| 计算 | `web/src/utils/`      | 格式化、GPU 空闲判断、磁盘排序等纯函数        |
| 组件 | `web/src/components/` | 节点卡片、GPU 行、磁盘列表、汇总栏            |
| 页面 | `web/src/pages/`      | 首页 `node-list`、详情页 `node-detail`        |

## 页面

### 首页 `/`

- 顶部汇总栏：在线节点上的空闲 GPU 数 / 总数，在线、失联、离线节点数，数据更新时间。
- 节点卡片网格，宽屏两列。排序：在线 → 失联 → 离线，同一状态内按 IP 自然排序。
- 卡片标题为 IP（等宽字体）加主机名；没有 IP 时只显示主机名。
- 每张 GPU 一行：序号、型号、利用率、显存、空闲标记。
- 磁盘两列，按剩余空间从多到少排序，默认显示 4 块，其余折叠；有将满的磁盘时在标题处标出块数。
- 失联、离线的卡片整体变淡，状态徽章显示距最后一次消息的时间。

### 详情页 `/nodes/:nodeID`

主机信息、GPU 表格、完整磁盘列表。进程表等 Controller 提供进程接口后加入。

## 关键规则

| 规则            | 取值                       | 位置                 |
| --------------- | -------------------------- | -------------------- |
| GPU 空闲        | 利用率和显存占比都低于 10% | `utils/usage.ts`     |
| GPU 满载        | 利用率或显存占比不低于 80% | `utils/usage.ts`     |
| 磁盘警告 / 严重 | 已用 90% / 95%             | `utils/usage.ts`     |
| 刷新间隔        | 5 秒                       | `api/useNodeList.ts` |

只在异常时着色，正常状态用中性色。

## 配色

提供白天与夜间两套配色，右上角按钮切换。未手动切换时跟随系统设置；手动选择保存在浏览器的 localStorage 中（键 `mantine-color-scheme-value`）。`index.html` 中的内联脚本在页面渲染前读取该值，避免刷新时闪烁。

## 断网

轮询失败时保留上一次成功的数据，汇总栏改为红字"与服务器断开，显示的是 HH:MM:SS 的数据"；恢复后自动消失。首次加载就失败时显示错误提示。
